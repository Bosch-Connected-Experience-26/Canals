# Problem

## Core Issue

Cloud-only voice assistants fail exactly when drivers need them most — tunnels, rural highways, cross-border dead zones.

## Consequences

- Voice commands time out with no signal
- Safety-critical queries (hospital, emergency) go unanswered
- Latency spikes during high-speed driving

## Hard Requirements

- LLM must run **fully offline** — no cloud dependency
- LLM must also work in **semi-connected** mode (partial cloud)
- Local data must be sufficient for most common queries
